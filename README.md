# Meridian Sync

DST-accurate remote team timezone planner built natively on `Intl.DateTimeFormat`.

## Features
- **Interactive 24h Team Grid**: Synchronized hourly timeline across any combination of global cities, color-coded for Core Work (`09–17`), Flexible (`07–08`, `18–20`), and Sleep (`21–06`).
- **Best Overlap Optimizer**: Evaluates all 48 half-hour slots across the day and surfaces top recommended meeting windows as one-click pills.
- **Customizable Roster & `localStorage`**: Add/remove teammates with roles and cities, toggle `12h / 24h` time display, pick future dates (DST-aware), and copy multi-timezone calendar invites.
